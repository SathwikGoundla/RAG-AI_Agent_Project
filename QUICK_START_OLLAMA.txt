🚀 SETUP & RUN (5 Steps)
─────────────────────────────────────────────────────────────────────

Step 1: Install Ollama
┌─────────────────────────────────────────────────────────────────┐
│ Windows: Download from https://ollama.com/download              │
│ macOS:   brew install ollama                                    │
│ Linux:   curl https://ollama.ai/install.sh | sh                │
└─────────────────────────────────────────────────────────────────┘

Step 2: Get phi3 Model
┌─────────────────────────────────────────────────────────────────┐
│ $ ollama pull phi3                                              │
│ (Downloads 2.7 GB model file)                                   │
└─────────────────────────────────────────────────────────────────┘

Step 3: Start Ollama Server
┌─────────────────────────────────────────────────────────────────┐
│ $ ollama serve                                                  │
│ (Runs on http://localhost:11434)                                │
│ Keep this terminal open!                                        │
└─────────────────────────────────────────────────────────────────┘

Step 4: Configure Environment (New Terminal)
┌─────────────────────────────────────────────────────────────────┐
│ $ cd c:\Users\Sathwik\advanced-rag-system                       │
│ $ cp .env.ollama .env                                           │
│ (Or manually add to .env:                                       │
│  OLLAMA_BASE_URL=http://localhost:11434                         │
│  OLLAMA_MODEL=phi3)                                             │
└─────────────────────────────────────────────────────────────────┘

Step 5: Start Project (Two More Terminals)
┌─────────────────────────────────────────────────────────────────┐
│ Terminal A (Backend):                                           │
│ $ cd backend                                                    │
│ $ python -m uvicorn main:app --reload                           │
│ → http://localhost:8000                                         │
│                                                                 │
│ Terminal B (Frontend):                                          │
│ $ cd frontend                                                   │
│ $ streamlit run app.py                                          │
│ → http://localhost:8501                                         │
└─────────────────────────────────────────────────────────────────┘


🔧 CONFIGURATION
─────────────────────────────────────────────────────────────────────

Config File: backend/config.py

OLLAMA_BASE_URL: str = "http://localhost:11434"
├─ Where Ollama server is running
├─ Default: localhost:11434
└─ Change if running on different machine

OLLAMA_MODEL: str = "phi3"
├─ Which model to use
├─ Options: phi3 (default), phi2, mistral, neural-chat, etc.
└─ Use: ollama list (to see installed models)


🧠 MODEL DETAILS
─────────────────────────────────────────────────────────────────────

Phi3 (Default):
├── Size: 3.8B parameters  
├── RAM: 2-4 GB
├── Speed: 2-5 sec/response
├── Quality: Very good
├── Language: English + multilingual
├── Format: 4-bit quantized
└── License: MIT (Free)

Alternatives:
├── Phi2 (2.7B) - Smaller, faster
├── Mistral (7B) - Larger, better quality  
├── Neural-Chat (7B) - Chat optimized
└── Tiny-Llama (1.1B) - Ultra fast

⚙️ API ENDPOINTS (Internal)
─────────────────────────────────────────────────────────────────────

All LLM calls go through Ollama:

POST http://localhost:11434/api/chat

Request:
{
  "model": "phi3",
  "messages": [
    {"role": "system", "content": "You are helpful..."},
    {"role": "user", "content": "Tell me about..."}
  ],
  "stream": false,
  "temperature": 0.3
}

Response:
{
  "model": "phi3",
  "created_at": "2024-01-01T00:00:00Z",
  "message": {
    "role": "assistant",
    "content": "Answer text..."
  },
  "done": true
}


🐛 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────

Problem: "Connection refused at http://localhost:11434"
Solution: Start Ollama server: ollama serve

Problem: "Model not found: phi3"
Solution: Pull model: ollama pull phi3

Problem: "Responses taking >10 seconds"
Solution: Check RAM usage, close other apps, or switch to phi2

Problem: "Module not found: openai"
Solution: Already removed! Don't need to install openai package

Problem: "OPENAI_API_KEY error"
Solution: Remove this from .env, use OLLAMA_* instead

Problem: "Ollama stops after request"
Solution: Ensure ollama serve is running in separate terminal

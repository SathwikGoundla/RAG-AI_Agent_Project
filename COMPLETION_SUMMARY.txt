🚀 QUICK START (5 STEPS)
───────────────────────────────────────────────────────────────────────────────

Step 1: Install Ollama
├─ Windows: Download from https://ollama.com/download
├─ macOS: brew install ollama
└─ Linux: curl https://ollama.ai/install.sh | sh

Step 2: Pull Phi3 Model
└─ $ ollama pull phi3
   (Downloads 2.7 GB model)

Step 3: Start Ollama Server
├─ $ ollama serve
├─ Runs on: http://localhost:11434
└─ Keep terminal open!

Step 4: Configure & Start Backend
├─ $ cp .env.ollama .env
├─ $ cd backend
└─ $ python -m uvicorn main:app --reload

Step 5: Start Frontend
├─ $ cd frontend
├─ $ streamlit run app.py
└─ Open: http://localhost:8501

🧠 ABOUT OLLAMA PHI3 MODEL
───────────────────────────────────────────────────────────────────────────────

Model: Phi3 (Microsoft)
├─ Parameters: 3.8 billion
├─ Quantization: 4-bit (default)
├─ Size on Disk: 2.7 GB
├─ RAM Required: 2-4 GB
├─ Speed: 2-5 seconds per response
├─ Language Support: English + multilingual
├─ Quality: Good (summarization, Q&A)
├─ License: MIT (Open source, free)
└─ Source: https://huggingface.co/microsoft/phi-3

Alternatives Available:
├─ Phi2 (2.7B) - Smaller, faster
├─ Mistral (7B) - Larger, better quality
├─ Neural-Chat (7B) - Chat optimized
└─ Tiny-Llama (1.1B) - Ultra fast

To switch models:
$ ollama pull [model-name]
# Update OLLAMA_MODEL in .env
# Restart backend

🐛 COMMON ISSUES & SOLUTIONS
───────────────────────────────────────────────────────────────────────────────

Issue: "Connection refused at http://localhost:11434"
Solution: 
├─ Check if Ollama is installed
├─ Run: ollama serve
└─ Verify running on port 11434

Issue: "Model not found: phi3"
Solution:
├─ Pull the model: ollama pull phi3
├─ Check available: ollama list
└─ Wait for download to complete

Issue: "OPENAI_API_KEY error still showing"
Solution:
├─ Make sure it's removed from .env
├─ Check backend/config.py has no OPENAI_API_KEY
└─ Restart backend process

Issue: "Responses taking >10 seconds"
Solution:
├─ Check system RAM available
├─ Close other applications
├─ Consider switching to phi2 (faster)
└─ Or use GPU acceleration if available

Issue: "ModuleNotFoundError: openai"
Solution:
├─ Already removed from requirements
├─ Don't need to install it
├─ Run: pip install -r backend/requirements.txt

📋 NEXT STEPS TO RUN PROJECT
─────────────────────────────────────────────

1. INSTALL OLLAMA
   Windows: https://ollama.com/download
   macOS: brew install ollama
   Linux: curl https://ollama.ai/install.sh | sh

2. PULL PHI3 MODEL
   $ ollama pull phi3
   (~2.7 GB download)

3. START OLLAMA SERVER
   $ ollama serve
   (Starts on http://localhost:11434)
   
4. VERIFY OLLAMA IS RUNNING
   $ curl http://localhost:11434/api/tags
   Should return JSON with phi3 model

5. CONFIGURE ENVIRONMENT
   $ cp .env.ollama .env
   # Update any settings if needed

6. START BACKEND (New Terminal)
   $ cd backend
   $ pip install -r requirements.txt  # Optional update
   $ python -m uvicorn main:app --reload
   # http://localhost:8000

7. START FRONTEND (Another Terminal)
   $ cd frontend
   $ streamlit run app.py
   # http://localhost:8501

8. TEST THE APPLICATION
   ✓ Upload a document
   ✓ Ask a question (uses Ollama)
   ✓ Generate a quiz (uses Ollama)
   ✓ Create a study plan (uses Ollama)
   ✓ Verify model shows "Phi3 (Local Ollama)"
